# cuill

A terminal-based text editor inspired by Emacs, written in Clojure.

## Overview

cuill is an experimental text editor that aims to bring the extensibility and power of Emacs to the Clojure ecosystem. Built on top of [Lanterna](https://github.com/mabe02/lanterna), it provides a cross-platform terminal UI experience.

## Requirements

- Java 8 or later
- Clojure CLI tools

## Installation

Clone the repository:

```bash
git clone https://github.com/conao3/clojure-cuill.git
cd clojure-cuill
```

## Usage

Run the editor:

```bash
clj -M -m cuill.core
```

## Project Status

This project is in early development. Contributions and feedback are welcome.

## Name

The name "cuill" is a portmanteau of "quill" and "Clojure". It is pronounced the same as "quill".
